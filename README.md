# Вишлист

Простой сайт для вишлиста.

- Быстрое добавление: вставь ссылку на товар или просто напиши желание
- Автопоиск по ссылке: название, цена и картинки со страницы товара — можно выбрать нужную картинку
  (через публичные сервисы microlink.io, r.jina.ai и CORS-прокси; для Wildberries картинки берутся с CDN по артикулу)
- Кнопка-закладка «＋ В вишлист» для магазинов, которые блокируют автопоиск (Ozon, DNS, Яндекс Маркет, Ситилинк…):
  собирает название, цену и картинки прямо со страницы товара в браузере
- Удаление: перетащи желание в корзину или нажми «Удалить» в карточке (можно отменить)
- Тир-лист S/A/B/C/D с перетаскиванием (мышью и пальцем), подписи уровней редактируются
- Карточки: название, ссылка, цена, картинка (по ссылке, с устройства или Ctrl+V), категория, комментарий
- Фильтр по категориям и сортировка по тиру или цене
- Отмечай, что уже подарили
- **Поделиться** — ссылка, в которую зашит весь список (только просмотр)
- Резервная копия в JSON и печать / PDF

Все данные хранятся только в браузере (localStorage), сервер не нужен.
Сайт публикуется на GitHub Pages workflow-ом из `.github/workflows/pages.yml`.
